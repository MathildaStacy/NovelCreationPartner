1. 页面功能

  • 默认列出本章正文中提到的档案条目，按出现次数从多到少排列。
  • 按名称、别名、摘要和字段内容搜索整部作品的档案。
  • 点条目原地展开只读详情，显示写到本章时的字段、别名和关系。
  • 需要修改时"在档案中打开"，进入 S12 条目详情。
  • 本弹窗不修改任何数据。

4. 数据与本地服务

打开弹窗

  • S07 传入：workId、chapterId、章节编号（番外、草稿为前一个正文章节的编号，见规则 3）、编辑器内存中的正文（存储格式，可能还没保存）。
  • 调用 entries.findMentions(workId, body)，得到 { entryId, name, count }[]；再调用 entries.list(workId) 取类型、状态、摘要，按 entryId 合并。

操作对应的服务

操作调用成功后
搜索entries.search(workId, query)（query 去掉首尾空白，为空时不调用）显示结果；只渲染最后一次请求的结果，较早返回的丢弃
展开条目entries.get(entryId, { atChapterId })渲染详情；同一次打开期间缓存结果，再次展开不重复读取
在档案中打开S07 立即保存（chapters.saveBody）→ 导航到 S12（参数 entryId）见元素表 6

订阅事件

  • entries.changed（弹窗打开期间，例如后台冲突检测把某字段标为有冲突）：清空详情缓存，重新执行当前列表的查询，已展开的条目保持展开并重新读取。
实施契约：atChapterId 始终传章节 ID。番外、草稿在服务中按作品阅读顺序取此前生效事实；页面显示它前面最近的正文章节编号。前面没有正文章节时按当前状态读取。

5. 业务规则

  1. 默认列表：findMentions 返回的条目中，排除已删除和已废弃的条目；按出现次数倒序，次数相同按名称拼音排序。最多显示 50 个。名称和别名的匹配次数合并计入同一条目。
  2. 搜索：范围是整部作品未删除的条目（不限本章）。已废弃的条目也显示，排在最后并带 已废弃 徽标。不显示出现次数。最多显示 50 个，超出时末尾提示"结果较多，请输入更具体的关键词"。
  3. 按本章时的状态：正文章节传本章 ID；番外和草稿同样传本章 ID，服务按阅读顺序求值，页面显示此前最近一个正文章节的编号（顶部显示"按第 N 章时的状态"）；前面没有正文章节时不传 atChapterId，顶部显示"按当前状态"。
  4. 详情显示内容（按 entries.get 返回）：
    • 别名（无则不显示）、一行摘要。
    • 当时有效的字段：字段名 + 值，按该类型字段模板的顺序（与 S12 一致）。字段状态为有冲突时字段名后加 有冲突；为提议时值用虚线框并加 提议（只读，不提供采纳按钮）。
    • 该字段在本章之后有新值时，值后加灰字"（第 M 章起有变化）"，不显示新值，避免剧透后文设定。
    • 当时有效的关系：关系类型 · 对方名称，最多 5 条，超出显示"等 N 条"。
    • 有未处理冲突时末尾显示"有 N 处未处理冲突"（只是提示，不可点击；处理冲突从编辑器的冲突提示条进入）。
  5. 弹窗高度：打开时占屏幕高度 75%；搜索框获得焦点时展开到全屏（顶部留出状态栏），键盘收起后回到 75%（G01 底部弹窗）。
  6. 本弹窗不调用任何写函数，不影响编辑器的撤销栈和保存状态。

6. 边界情况

  • 正文还没保存（2 秒计时未到）：用的是编辑器内存中的正文，刚写下的名字也能匹配到。
  • 两个条目名称重叠（如"星海"与"星海之镜"）：findMentions 最长匹配优先，"星海之镜"中的"星海"不计入"星海"。
  • 超长章节（5 万字以上）：查找可能较慢，显示骨架；超过 3 秒仍未返回时保持骨架，不超时报错。
  • 从 S12 返回编辑器后弹窗不会自动重新打开；再次点"档案"时重新查询，在 S12 中删除的条目不再出现。
  • 条目只有提议字段（如 AI 伙伴暂存的人物）：照常显示，全部字段为虚线提议样式。

7. 验收要点

  • 在第 10 章打开档案速查，"林宇""老周""沈汐"等按出现次数排列，次数与正文一致（别名计入）。
  • 刚输入一个人物名、未等自动保存就打开，该人物出现在列表中。
  • 搜索"镜"能找到"星海之镜"；删空搜索框回到本章列表。
  • 某字段在第 11 章改过：在第 10 章查看显示旧值并标"第 11 章起有变化"；在第 12 章查看显示新值。
  • 在番外中查看，顶部显示"按第 N 章时的状态"，N 为它前面最近的正文章节。
  • 点"在档案中打开"进入 S12；返回后回到编辑器，正文已保存、光标位置不变。
  • 关闭弹窗后编辑器的撤销、重做状态不变。
