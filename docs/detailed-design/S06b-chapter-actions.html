1. 页面功能

  • 对单个章节执行：编辑信息、移到其他卷、定稿本章、撤销定稿、查看版本历史、导出本章、删除。
  • 菜单项按章节类型和状态显示或隐藏，不出现点了也不能用的项（"定稿本章"正文为空时除外，见 #5）。
  • V1 不提供"复制章节"；需要另起一版时，在编辑器"存为版本"或新建草稿章节后粘贴。

2. 元素与操作

#元素显示规则操作结果 / 去向
1被长按的章节行长按 500 ms 触发，轻震动一次；该行显示选中底色直到操作表关闭——
2菜单标题"{编号或番外/草稿} {标题} · {状态} · {字数}"，单行，超出省略；状态用 G02 4.3 的名称，番外和草稿不显示状态——
3"编辑章节信息"始终显示点击关闭操作表，打开 S06a 章节信息（编辑模式）
4"移到其他卷"作品卷数 ≥ 2 时显示点击打开二级操作表：标题"移到哪一卷"，按顺序列出所有卷名，当前所在卷后带"（当前）"且置灰；底部"取消"。选中后调用 chapters.update(chapterId, { volumeId })，章节放到目标卷末尾，提示条"已移到「{卷名}」末尾"
5"定稿本章"正文章节（kind = 'main'）且状态为草稿或有修改未定稿时显示点击正文为 0 字：不打开对话框，提示条"正文还是空的，写点内容再定稿"。否则关闭操作表，弹 S07b 定稿本章确认；确认、提示和后台任务与在编辑器中定稿完全相同，完成后留在 S06
6"撤销定稿"正文章节且状态为已定稿或有修改未定稿时显示点击直接调用 chapters.unfinalize(chapterId)，不再二次确认；成功后提示条"已撤销定稿，本章回到草稿"，列表状态徽标变为"草稿"
7"版本历史"始终显示点击压栈进入 S07d 版本历史（参数 chapterId），返回回到 S06
8"导出本章"正文和番外章节显示；草稿章节不显示（导出只含正文和番外）点击进入 S15b 导出，预选"导出正文"、当前作品、只勾选本章
9"删除章节"始终显示，排在最后；文字用默认颜色，不用朱红（与 S03a 一致，由确认弹窗把关）点击弹 D02 删除章节确认。确认后 chapters.remove(chapterId)，行消失，提示条"已移到回收站"+"撤销"（5 秒，trash.restore('chapter', chapterId)）
10"取消"独立分组点击；点遮罩；下滑；Android 返回键关闭操作表，不做任何改动

状态条件表现
正文 · 草稿kind = 'main'，state = 'draft'显示 #3 #4 #5 #7 #8 #9
正文 · 已定稿state = 'finalized'显示 #3 #4 #6 #7 #8 #9（不显示"定稿本章"）
正文 · 有修改未定稿state = 'modified'显示全部 #3–#9；"定稿本章"即重新定稿
番外kind = 'extra'显示 #3 #4 #7 #8 #9
草稿类章节kind = 'draft'显示 #3 #4 #7 #9
整理中该章有排队或运行中的整理任务（列表显示"整理中…"）菜单项不变；"定稿本章"会取消旧任务重新入队（G02 chapters.finalize）
操作失败NOT_FOUND提示条"这一章已被删除"，列表刷新
DB_ERROR / STORAGE_FULL按 G01 错误处理弹对话框；数据不变

4. 数据与本地服务

时机调用说明
打开不调用服务使用 S06 已载入的 ChapterListItem（类型、状态、字数）决定菜单项；卷数取 S06 已载入的分组数
移到其他卷chapters.update(chapterId, { volumeId })移到目标卷末尾，重算编号；发出 chapters.changed
定稿本章由 S07b 调用 chapters.finalize(chapterId)见 S07b；发出 chapters.changed、jobs.changed
撤销定稿chapters.unfinalize(chapterId)状态改回草稿，保留全部快照和已通过的记忆；发出 chapters.changed
删除 / 撤销删除由 D02 调用 chapters.remove(chapterId)；撤销调用 trash.restore('chapter', chapterId)删除取消该章排队中的任务；恢复按 G02 4.1

5. 业务规则

  1. 定稿只对正文章节开放；番外和草稿类章节不显示定稿相关项（G02 4.3）。
  2. "定稿本章"在列表与编辑器中行为一致：同一个 S07b 对话框、同样的快照和三项后台任务。
  3. 撤销定稿不删除定稿快照，不撤回已通过审核写入档案的设定，不取消已排队的整理任务；产生的提案仍进入 S13 记忆审核，由作者决定是否接受。
  4. 撤销定稿不提供"撤销"按钮；需要时再次"定稿本章"即可（会重新整理）。
  5. 移到其他卷只放到目标卷末尾；精确位置用 S06d。
  6. 删除进回收站保留 30 天；已通过的记忆出处显示"（已删除的章节）"。

6. 边界情况

  • 长按期间列表因后台任务刷新：操作表保持打开，菜单项按打开时的数据；执行时以服务返回为准。
  • 把唯一一章正文移到靠前的卷：后续正文编号随之变化，提示条只显示移动结果。
  • 撤销删除时原卷已被删除（只可能在 5 秒内删空卷，实际不会发生，因为卷内有回收站章节时不能删卷）。
  • 已定稿章节正文为 0 字（定稿后又清空）：状态为有修改未定稿，"定稿本章"点击后提示正文为空，"撤销定稿"可用。

7. 验收要点

  • 长按章节行 500 ms 弹出操作表，标题显示章节编号、标题、状态和字数。
  • 草稿状态正文只有"定稿本章"，已定稿只有"撤销定稿"，有修改未定稿两者都有；番外、草稿类章节两者都没有。
  • 从菜单"定稿本章"弹出的对话框与编辑器中的一致，确认后列表显示"整理中…"。
  • "撤销定稿"后徽标变为"草稿"，版本历史中的定稿快照仍在，档案内容不变。
  • 只有一卷时不显示"移到其他卷"；移到第二卷后章节出现在第二卷末尾，编号正确。
  • "删除章节"文字不是红色；确认后提示条"撤销"能恢复到原位置。
  • 草稿类章节不显示"导出本章"。
