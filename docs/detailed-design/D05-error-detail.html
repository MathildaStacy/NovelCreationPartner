1. 元素与操作

#元素显示规则操作结果
1说明与出错位置显示的文案相同（G03 第 8 节或 G02 第 8 节）——
2字段列表按下表，值为空的行不显示。长值自动换行，可长按选择——
3服务商信息G03 归一器生成的安全诊断（providerMessage），不展示任意服务商原文；未知或疑似含敏感回显时省略——
4"复制详情"始终显示点击按第 3 节格式复制到剪贴板，提示条"已复制"
—关闭右上 ✕、下滑、遮罩、Android 返回键点击关闭弹窗

2. 字段

字段AI 错误本地错误来源
服务是否AiErrorInfo.serviceName
协议是否服务的 protocol，显示为"OpenAI Responses"或"Anthropic Messages"
模型是否AiErrorInfo.model
请求地址是否resolveUrl 结果，去掉协议头、查询参数和片段
状态码是（网络错误时显示"未收到响应"）否status + 内部错误码
服务商信息是否providerMessage
Request ID是否requestId（响应头 x-request-id 或 request-id，或错误体中的 request_id）
错误码—（并入状态码行）是AppError.code，如 DB_ERROR
技术信息否是本地白名单诊断（不含原始异常/堆栈），最多 300 字
时间是是格式见 G01 时间
App 版本仅复制内容中仅复制内容中版本号与构建号

永远不显示、不复制：API Key（含掩码）、请求体、提示词、正文和模型输出。

时间在复制内容中用完整格式（含时区），便于服务商排查。

4. 数据与本地服务

不调用服务。调用方传入 AiErrorInfo（AI 错误）或 AppError（本地错误）。AI 伙伴消息的错误来自 Message.error，后台任务的错误来自 Job.error。

5. 验收要点

  • 用错误的 Key 测试连接，详情中有状态码 401、服务商信息和 Request ID。
  • 复制的文本中没有 Key 的任何部分，也没有正文内容。
  • 断网时出错，状态码显示"未收到响应"。
