1. 触发条件

页面或弹窗处于"有改动"状态（当前值与打开时的值不同，逐字段比较；改了又改回去不算改动），并且发生以下任一操作：点返回或关闭、iOS 侧滑返回、Android 返回键、下滑关闭底部弹窗、点弹窗遮罩。没有改动时直接离开，不弹出。

章节正文自动保存，编辑器不使用本对话框；编辑器保存失败时使用 S07 自己的"未保存"对话框。

2. 元素与操作

#元素操作结果
1标题—默认"放弃未保存的修改？"，变体见第 3 节
2正文—默认"现在离开，刚才填写的内容不会保存。"
3"放弃修改"点击丢弃改动，执行原来的离开动作
4"继续编辑"点击；Android 返回键、点遮罩等同关闭对话框，留在原处，输入内容和焦点不变

4. 数据与本地服务

无。改动判断由各页面的表单状态完成，建议统一使用 useDirtyGuard(isDirty) 钩子，同时拦截导航返回事件（React Navigation beforeRemove）和弹窗关闭事件。

5. 验收要点

  • 改了表单再返回（按钮、侧滑、Android 返回键、下滑弹窗）都会出现确认；没改动时直接离开。
  • 点"继续编辑"后输入内容完整保留。
  • 各页面文案与第 3 节一致。
