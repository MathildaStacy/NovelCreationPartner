1. 页面功能

  • 按卷分组列出章节，显示编号、标题、状态、字数、更新时间和一行摘要。
  • 新建章节；新建、重命名、删除卷。
  • 进入章节编辑器。
  • 章节操作：编辑信息（标题、类型、所属卷）、删除。
  • 调整章节顺序（可跨卷）。
  • 标出有设定冲突的章节，可直接进入冲突处理。
2026-10-19 实施同步：左滑露出“更多”（灰，打开 S06b）和“删除”（错误色，打开 D02，成功后提示条可撤销）；长按仍直接打开 S06b。行操作使用公共 components/SwipeRow（PanResponder，无新增原生依赖）：只接管明显横向的拖动，纵向交给列表；同一列表同一时间只展开一行，滚动列表或点任意行先收起；收起中的按钮立即不可点并对读屏隐藏，动画结束后卸载；减弱动态效果时直接到位。读屏用户通过 accessibilityActions 获得同样的操作，不依赖手势。真机手势手感、两端触控与大字布局仍待设备验收。

4. 数据与本地服务

进入页面

  • 调用 chapters.list(workId)，得到按卷分组的章节（不含正文）。卷合计数在界面层由列表计算。
  • 调用 jobs.list(workId, { active: true })，用于"整理中…"标记。

订阅事件

  • chapters.changed、chapter.saved：重新读取列表（保留滚动位置）。
  • conflicts.changed：刷新冲突徽标。
  • jobs.changed：刷新"整理中…"标记。

操作对应的服务

左滑删除并确认chapters.remove(id)行消失；提示条"已移到回收站"，操作"撤销" → trash.restore('chapter', id)

5. 业务规则

  1. 排序：卷按顺序，卷内按章节顺序。番外和草稿与正文混排在作者安排的位置，不占章节编号（G02 4.4）。
  2. 卷合计"N 章 X 字"只统计正文章节；页面不显示全书合计（全书合计在 S05 概览）。
  3. 字数格式见 G01 数字（如 7204 字、8.2 万字）。
  4. 摘要最多显示 1 行，超出以省略号截断。
  5. 已在回收站的章节不显示。

6. 边界情况

  • 删除的章节有未处理冲突：冲突一起隐藏（不再计入角标）；从回收站恢复后重新出现。
  • 删除的章节有待审核的记忆提案：提案保留，在 S13 中该组标题显示"（已删除的章节）"，"跳到原文"不可用。
  • 正在编辑器中打开的章节在另一入口被删除（如从回收站相关操作）：V1 只有单窗口，不会发生。
  • 章节很多（≥ 300 章）：列表使用虚拟化（SectionList），滚动保持流畅。

7. 验收要点

  • 新建作品后进入章节页，显示空状态和"新建第一章"。
  • 正文章节连续编号；插入番外后，后续正文编号不变。
  • 修改一章已定稿的正文后返回，状态变为"有修改未定稿"；改回原文后恢复"已定稿"。
  • 有冲突的章节显示冲突徽标，点击能到对应冲突。
  • 左滑删除后可通过提示条撤销；30 天内可在 S15d 回收站恢复。
  • 切换到其他标签再回来，滚动位置不变。
