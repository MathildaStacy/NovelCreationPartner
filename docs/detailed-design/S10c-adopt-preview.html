1. 页面功能

  • 调用 AI 把所选方向拆成若干待写入项（AdoptItem）：每项是"新建某条目"或"更新已有条目的某些字段"。
  • 逐项预览：类型、名称、字段和值；更新项显示新增或修改了哪些字段及原值。
  • 可编辑每项的名称、类型、字段名和字段值，可增删字段，可取消勾选整项。
  • 与已有条目重名时默认合并为更新；可改为新建，但必须改名。
  • "写入档案（N 项）"一次写入全部勾选项，状态为已确认，回到 S10 后方向卡收起为一行。
  • 拆解失败时可以重试，或"手动整理"进入条目编辑页自己填写。

4. 数据与本地服务

打开弹窗

  • 调用前的网络、模型服务、AI 数据说明检查由入口页（S10 调用 AI 前的检查）完成。
  • 调用 ai.splitForAdoption(messageId, optionIndex) → AdoptItem[]（提示词与输出结构见 G03 拆解）。本次打开作品期间同一"消息 + 选项"已拆解过时直接使用缓存，不再调用模型。
  • 拆解结果返回后，界面层对每项用 entries.search(workId, name) 查找同类型、名称或别名完全相同的未删除条目，决定新建还是更新；更新项再用 entries.get(entryId) 读取当前字段，标出新增 / 修改（值完全相同的字段直接去掉）。
需要新增：在 G02 第 2 节定义 AdoptItem = { action: 'create'|'update'; type: EntryType; name: string; targetEntryId: ID|null; summary: string; facts: { field: string; value: string; before: string|null }[] }。ai.splitForAdoption 只返回 type、name、summary、facts；action、targetEntryId、before 由上面的匹配步骤填写。

订阅事件

  • entries.changed：弹窗打开期间重新执行重名匹配。已编辑过的项不自动改变动作，只在名称下方提示"档案刚刚有变化，请检查"。

5. 业务规则

  1. 写入后的状态：所有写入的条目字段状态为已确认，来源为 AI 伙伴（partner）。更新项中被修改的字段按 G02 entries.update 的方式保留旧值历史。
  2. 拆解数量：一个方向最多拆成 8 项；每项最多 20 个字段。超出部分由 G03 截断。
  3. 项的显示：标题"新建 人物「沈汐」"/"更新 世界观「星海之镜」"。字段行：新建项写"字段名 值"；更新项写"新增字段 线索：值"或"修改字段 能力：原值 → 新值"。项按"更新在前、新建在后"，同类按 AI 返回顺序。
  4. 校验（只对勾选项）：名称去掉首尾空白后 1–30 字；字段名 1–20 字，同一项内不重复；字段值 1–500 字；摘要 0–100 字。同一次写入中两个勾选项不能同类型同名（"这次写入中已有同名的{类型}"）。
  5. 重名：同类型下名称或别名与未删除条目完全相同（含提议状态和已废弃的条目）时，默认合并为更新该条目。改为新建时必须改名，否则 entries.adopt 会抛出 DUPLICATE（G02 entries.create 的重名规则）。不同类型同名允许，不提示。
  6. 更新已废弃的条目：合并说明改为"档案中的「{名称}」已废弃，写入后将恢复使用"，写入时一并 entries.unretire。
  7. 手动整理预填（进入 S12a 新建模式）：类型为拆解结果第一项的类型，拆解失败时为"世界观"；名称为方向标题（超过 30 字截断）；摘要为一句话概括；备注字段为"走向：…\n风险：…\n影响：…"。
  8. 手动整理不改变方向卡状态：S12a 保存的条目来源为手动，与这条回复无关联，方向卡仍为 open，你可以之后再采纳或暂存。
  9. 只有 open 状态的方向可以打开本弹窗；从 S10d 打开时也一样。
待确认：采纳时是否需要让你指定"自第 N 章起生效"？当前设计：写入的字段生效区间为空（设定层面始终有效），需要时到 S12 中修改。

6. 边界情况

  • 拆解中切换底部标签：弹窗随 S10 保持，请求继续；回来时看到结果。离开作品时中止，方向卡不变。
  • 写入后马上点撤销：按 S10 的撤销规则恢复，本次新建的条目被删除、更新的字段恢复旧值。
  • 同一方向在拆解期间被另一操作改变状态（例如在 S10d 中对同一方向点了"暂存"）：写入时检查选项仍为 open，否则抛出 CONFLICT_STATE，提示"这个方向已经处理过"，关闭弹窗。
  • 所有项都是更新且字段值与档案完全相同：拆解后为 0 项，按"拆出 0 项"处理，说明改为"这个方向的设定档案里都已经有了。"
  • 名称里含有"「」"等符号：原样保存，显示时不转义。

7. 验收要点

  • 打开后先显示"正在把这个方向整理成档案条目…"，完成后列出新建和更新项，文案格式如"新建 人物「沈汐」""更新 世界观「星海之镜」：新增字段 线索"。
  • 档案中已有"星海之镜"时，同名项默认为更新；点"改为新建"后不改名无法写入。
  • 取消勾选的项不写入；"写入档案（N 项）"中的 N 随勾选变化。
  • 修改名称和字段值后写入，档案中保存的是修改后的内容，状态为已确认。
  • 写入后回到 S10，方向卡收起为一行"已采纳为设定"；撤销后档案恢复原状。
  • 断网时拆解失败，显示原因、"重试"和"手动整理"；"手动整理"进入 S12a 且名称预填为方向标题。
  • 编辑过内容后关闭，出现 D04；未编辑直接关闭。
