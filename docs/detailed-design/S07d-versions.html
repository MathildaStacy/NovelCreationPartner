1. 页面功能

  • 按时间倒序列出本章的全部版本，按日期分组。
  • 每个版本显示来源（自动 / 定稿 / AI 插入前 / 手动 / 恢复前）、时间、字数、与现在相比的字数差。
  • 标出当前定稿对应的版本。
  • 点击版本进入对比与恢复。

4. 数据与本地服务

进入页面（并行）

  • versions.list(chapterId)：版本列表（倒序，不含正文），每项含来源、字数、创建时间。
  • chapters.get(chapterId)：取编号、标题、类型、当前字数 charCount、finalizedVersionId。从 S07a 进入时编辑器已立即保存，所以数据库中的正文就是"现在"。

订阅事件

  • versions.changed（本章）：重新调用 versions.list，保留滚动位置。
  • chapter.saved（本章）：用载荷中的 charCount 更新"现在 X 字"和每行字数差（例如在 S07e 恢复后）。
  • chapters.changed：重新读取标题、编号和 finalizedVersionId。

5. 业务规则

  1. 排序：按创建时间倒序（最新在上），与 versions.list 一致。日期分组按本地时区自然日。
  2. 字数差 = 版本字数 − 现在字数（两者都按 countChars）。大于 0："比现在多 N 字"；小于 0："比现在少 N 字"；等于 0："与现在字数相同"。N 的格式见 G01 数字。字数相同不代表内容相同，内容是否相同在 S07e 中判断。
  3. 保留规则见 G02 4.2：自动版本每章最多 50 个、AI 插入前最多 30 个，超出时删除最旧的同类版本；定稿、手动、恢复前永久保留。插入 AI 文本前若正文与最近的自动版本相同，该版本改标为"AI 插入前"；与定稿等永久版本相同则沿用该版本。本页不提供删除版本的操作。
  4. 本页只读，不改变章节正文和状态。
  5. 列表使用虚拟化（FlatList/SectionList），一章可能有 100 个以上版本。

6. 边界情况

  • 从 S06b 进入，章节正文为空且没有版本：显示空状态，不显示"存为版本"按钮。
  • 从 S07a 进入时编辑器保存失败：编辑器不打开本页（见 S07 立即保存）。
  • 章节已定稿后又撤销定稿：finalizedVersionId 为空，不显示"当前定稿"标记，原来的定稿版本仍以"定稿"来源保留。
  • 在 S07e 恢复版本后，本页（如在栈中）通过事件刷新：顶部出现新的"恢复前"版本，字数差全部按新的现在字数重算。
  • 同一分钟内有多个版本：时间相同，按创建时间的先后排列，不合并。

7. 验收要点

  • 在编辑器修改后返回，再进入版本历史，顶部多一个"自动"版本。
  • 插入一次 AI 文本后，出现"AI 插入前"版本，字数为插入前的字数。
  • 定稿后出现"定稿"版本并带"当前定稿"标记；再次定稿后标记移到新的定稿版本。
  • 字数差的正负和数值正确；修改正文后返回本页，字数差随之更新。
  • 从 S06b 进入，返回回到章节列表；从 S07a 进入，返回回到编辑器且光标不变。
  • 新章节没有版本时显示空状态，"把现在的内容存为版本"可用。
