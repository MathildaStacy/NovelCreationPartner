1. 页面功能

  • 统一承载两类写作辅助：
    1. S08 描写助手（ai.describe）：标题显示所选描写类型（如"描写候选 · 环境氛围 + 动作细节"），左下链接"调整要求"可回到 S08 修改条件。
    2. S07 选区快捷操作（ai.quickEdit）：作者选中 1–2000 字后点改写、扩写、缩写、润色或补细节，跳过 S08 打开发送预览，明确确认后进入候选，count = prefs.candidateCount，标题显示"选区扩写"等对应操作名。
  • 多版本流式：打开即发起 count 个独立的流式请求（同时进行，G03 前台并发上限 3），每个版本一页，可翻页比较；当前版本实时显示字数，可停止。
  • 再写一版：先展示参考范围和预计消耗；点击“发送”后在末尾追加一个新版本并单独请求，累计最多 5 个版本。
  • 安全采纳："插入到光标处 / 替换所选文字"调用 chapters.applyAiText：先自动保存 before_ai 快照再写入，编辑器记一步可撤销的操作。
  • 错误：按 G03 错误码显示文案与对应操作，"查看详情"打开 D05；一个版本失败不影响其他版本。

5. 业务规则

  1. 不采纳不改正文：生成过程不写库；候选只在内存中（G03 1 第 7 步"描写候选不落库"），正文不落库；所有物理尝试仍保存无正文的用量账本（G04 9）。
  2. 先快照后写入：每次插入或替换都由 applyAiText 在同一事务内先生成 before_ai 快照；正文与最近快照相同时不新建。快照在 S07d 显示为"AI 插入前"。
  3. 可撤销：AI 插入算编辑器撤销栈中的一步（类型 ai）；撤销后正文回到插入前、选区恢复，before_ai 快照保留。
  4. 章节状态：已定稿的章节被插入或替换后变为"有修改未定稿"（G02 章节状态规则）。
  5. 版本数：首次 1–3（count），"再写一版"后累计最多 5；同时进行的请求不超过 3 个，超出的排队等待。
  6. 选区 1–2000 字（S07 已限制）；range 为存储偏移，打开期间编辑器不可操作，range 不会失效。
  7. 后处理：去掉首尾空白和成对外层引号，按 G02 4.6 规范化段落（G03 6.6）。
  8. Key 只从系统钥匙串读取，只发送 G03 5.2 规定的上下文。

6. 边界情况

  • 多个版本全部失败：分段栏全部显示"失败"，当前版本显示错误块；"再写一版"仍可用。
  • 一个版本已完成、其他仍在生成时插入：其他请求被中止并丢弃，不再弹 D04。
  • 模型输出为空（完成但 0 字）：状态"没有生成内容"，可重试，#8 禁用。
  • App 切到后台：请求不主动中止（G03 10），回到前台按超时规则判断；若进程被回收，候选丢失，正文不变。
  • 采纳时快照失败（如存储空间不足）：整个事务回滚，正文不变，按"采纳失败"处理。
  • 服务不支持流式（中转服务忽略 stream）：按 G03 3 非流式兜底，文字一次性出现，其余行为相同。
  • 离线：请求前管道抛出 AI_NETWORK，按 G01 离线提示，版本显示失败块。

7. 验收要点

  • 从 S08 选 2 个版本：两个版本同时流式出现，可切换比较，切换时后台版本继续生成。
  • 选区点"扩写"：先展示参考范围与预计消耗，确认后进入候选；版本数等于 S15e 的 candidateCount，标题为"选区扩写"。
  • 流式中途点"停止生成"，已生成文字保留，标"已停止"，可直接插入。
  • "再写一版"追加新版本，累计到 5 个后按钮置灰。
  • 不点插入/替换而直接关闭：有已完成候选时先弹 D04；确认后正文无任何变化。
  • 点"替换所选文字"后，S07d 版本历史出现一条"AI 插入前"快照；在编辑器点"撤销"一键还原。
  • Key 无效时当前版本显示"API Key 无效或已失效。"，"查看详情"打开 D05；其他版本不受影响。
  • 输出达到上限时显示"继续生成"，续写的文字追加在同一版本末尾。
  • 在候选正文卡上左右滑动可切换版本。
  • 多次“再写一版”叠加时，全局同时生成最多 3 个，其余排队。
  • S09 内服务消失时直接打开 D03，取消不发送。

2026-10-18 实施同步 · B 写作

新用户候选默认 1，已有显式 1/2/3 保留。S08/S09 使用同一不可变 ContextPlan 预览与发送，手选参考与相关必要事实不可静默裁剪；变化需重新预览。描写默认输出 2k，长选区按目标本地估算至 4k 并预览，不能自动翻倍。

迁移 0004 新增 ai_requests/ai_attempts。逻辑操作 N+2 次 POST、每候选最多 3 次，参数降级/重试共用预算与 5 分钟期限。每次连接测试 POST 也记账，连接测试仍沿用 20 秒 ping64/最多4次的独立规则；列表 GET 不计 token。未知用量/费用保留 NULL，不以零显示。账本不保存正文、提示词、Key、完整 URL、原始异常。

候选只保留内存。插入由作者点击，事务内核对 expectedBody，先存 before_ai；编辑器再校验会话、记独立撤销步。停止保留文字；关闭取消全部请求，不触发隐式重发。真实设备/模型效果未测。
