1. 页面功能

  • 用 S02 当前草稿和 Key 输入框内容调用 modelServices.test(draft, key, {signal})（内部为 ai.testConnection，G03 6.1）：先取模型列表，再发一次输入为"ping"、最大输出 64 的流式请求。
  • 显示三种结果：测试中（可取消）、成功（用时、回复模型、模型数、流式支持、模型不在列表的提醒）、失败（按错误码归为 6 类，给出一句话原因和对应的修改入口，可查看 D05）。
  • 把探测到的流式能力写回草稿 caps.streaming，随 S02 保存入库。
  • 测试结果决定 S02 点"保存"时是否弹出提醒对话框（第 5 节规则 6）。

5. 数据与本地服务

modelServices.test(draft, key, {signal}) → TestResult      // G02 5.11，内部调用 ai.testConnection（G03 6.1）
TestResult 以 G03 6.1 为准，另含 at、models、responseModel、capsPatch；不在本页重定义类型。
  • key：Key 输入框内容（已按 S02 规则 5 清理）；edit 模式输入框为空时传 undefined，服务层用 draft.id 已保存的 Key。S15a 变体中 draft 为 modelServices.get(id) 的结果，key = undefined，调用显式传 {signal, persist:true}。
  • lastTest：S02 所有草稿测试均不写库；S15a persist=true 仅在服务 revision 和最新测试序号仍匹配时写 lastTest/emit，否则 CONFLICT_STATE（已删除为 NOT_FOUND）。见 G02 5.11.3。S02 保存时再按 S02 第 5 节"保存"第 3 步决定保存的 lastTest。message 成功时为"连接正常"，失败时为第 4 节第二行文案。
  • 回复模型：取生成响应中的 model 字段（OpenAI Responses 与 Anthropic Messages 响应体都有）；缺失时显示所填模型名。与所填模型不同时（如中转映射）显示 G03 校验/脱敏后的响应值，不报错。
  • 能力写回：streaming 为布尔值时写入草稿 options.caps.streaming；推理强度参数被拒后按 G03 4.2 去掉重发的，同时写入 caps.effort = false。
  • 测试只发"ping"，不含作品内容，不经过 D03 / D01。

6. 业务规则

  1. 超时：整个测试（列表分页、生成、等待与降级）共享 20 秒总期限，见 G03 6.1。到期 AI_TIMEOUT；列表仅 404/405 可跳过，超时不能继续生成。
  2. 重试：AI_RATE_LIMIT、AI_SERVER 按 G03 第 9 节前台规则最多自动重试 2 次（等待 1 秒、3 秒，或按 retry-after，单次最多等 20 秒）；重试计入「已用秒数」，不重置整个测试的 20 秒期限；只有生成阶段可重试，列表不自动重试。其他错误不重试。
  3. 用时：latencyMs 从最后一次实际生成尝试发出到收到终态，不含模型列表请求和重试等待。显示为秒，保留 1 位小数（四舍五入），低于 0.1 秒显示"0.1 秒"。超过 10 秒时追加琥珀色"响应较慢，生成长内容时可能要等更久。"
  4. 同一时间只有一次测试：测试中按钮禁用；连接字段改动、点"取消"、返回、点"保存"都会中止当前测试（中止不写 lastTest）。
  5. 结果只在内存：本页的测试结果不随页面保留；离开 S02 再进入时只显示"上次测试"灰字。
  6. 保存与测试结果的关系（与 S02 第 5 节"保存"第 2 步一致）：
    • 未测试、测试被取消、测试中点保存（先中止）、或最后一次测试后连接字段有改动 → 对话框"还没有测试连接"，正文"不测试也可以保存。地址、Key 或模型有误时，要到第一次使用 AI 时才会发现。"，按钮"先测试" / "直接保存"。点"先测试"关闭对话框并立即执行测试，不自动保存。
    • 最后一次测试成功且之后无连接字段改动 → 不弹对话框，直接保存，lastTest.ok = true。
    • 最后一次测试失败且之后无改动 → 对话框"连接测试没有通过"，正文为第 4 节第二行文案，按钮"继续修改" / "仍然保存"。"继续修改"关闭对话框并执行该分类的修改按钮动作；"仍然保存"保存且 lastTest.ok = false，S15 列表显示该失败状态。
    • edit 模式下连接字段和 Key 都没改动 → 不论测试结果都不弹对话框。

7. 边界情况

  • 系统报告无网络时点测试：不发请求，直接显示"连不上服务"，第二行"手机没有联网，请检查网络后重试。"
  • 测试中 App 切到后台：请求继续；超过 20 秒仍未返回时按超时处理，回到前台看到结果。
  • 测试成功后只改了名称再保存：仍按"测试成功"处理，不弹对话框。
  • edit 模式先测试通过、再改 Key、又改回原样：Key 输入框非空即视为改动，结果失效，需要重新测试。
  • 服务商错误体中含有请求回显的 Key 片段：D05 展示前由 G03 适配器脱敏，结果区和 lastTest.message 中也不出现 Key。
  • 测试中服务被另一处删除（S15a 变体）：NOT_FOUND，提示条"这个模型服务已被删除"，不显示测试结果。

8. 验收要点

  • Base URL 为空时点"测试连接"只显示字段错误，不发请求。
  • 正确配置测试成功：显示"连接成功"、用时（1 位小数）、回复模型名、可用模型数；按钮变为"重新测试"。
  • 所填模型不在列表但请求成功：显示琥珀色提醒，仍判为成功，保存不弹对话框。
  • 错误 Key → "Key 有问题"，点"修改 Key"聚焦 Key 输入框；点"查看详情"打开 D05 且详情中无 Key 原文。
  • OpenAI 协议填 Anthropic 官方地址 → "协议或地址不对"；断网 → "连不上服务"；用不存在的域名 → AI_NETWORK。
  • 模拟 20 秒无响应 → 显示"{域名} 没有响应"；测试中点"取消"后结果区消失，点保存弹"还没有测试连接"。
  • 测试成功后改模型，结果区消失；改最大输出，结果保留。
  • 测试失败后保存弹"连接测试没有通过"；"仍然保存"后 S15 该服务显示未通过状态。
  • 从 S15a 测试：不进入 S02，服务行显示"测试中…"，结束后弹带"查看详情"的提示条。
