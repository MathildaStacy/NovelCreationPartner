1. 通用规则

#元素规则
1标题"删除「{名称}」？"。名称超过 12 字时截断并加省略号。没有名称时用对象类型（如"删除这部作品？"）
2正文说明会一并处理哪些内容、能否恢复。按下面各节
3"取消"左侧。关闭对话框，不做任何事。Android 返回键、点遮罩等同取消
4删除按钮右侧，品牌色加粗，文案写明对象（"删除作品""删除章节"）。点击后按钮显示加载状态，调用对应函数；成功关闭对话框并显示提示条；失败关闭对话框，按 G01 错误展示

进入回收站的对象，成功后的提示条带"撤销"（5 秒，G01 提示条），撤销调用 trash.restore(kind, id)。直接删除的对象没有撤销。

2. 作品

入口S03a 作品操作"删除"、S05a 作品信息底部"删除作品"
标题删除「星海之境」？
正文作品连同 12 个章节、档案和 AI 伙伴对话会移到回收站，30 天内可以恢复。（章节数为该作品全部章节，含番外和草稿；0 章时省略"连同 N 个章节"）
按钮删除作品
调用works.remove(workId)（不改任务表；由队列跳过已删除作品）
成功后从 S05a 删除时返回书架；提示条"已移到回收站"+"撤销"

3. 章节

入口S06 左滑"删除"、S06b 章节操作"删除"
标题删除「海边的相遇」？（用章节标题，不加编号）
正文章节会移到回收站，30 天内可以恢复。已经审核通过、写进档案的设定不受影响。
该章有待审核的记忆变更时追加："这一章还有 3 条待审核的记忆变更，会保留在审核列表里。"
按钮删除章节
调用chapters.remove(chapterId)（取消该章排队中的任务）
成功后提示条"已移到回收站"+"撤销"

4. 卷

入口S06c 卷管理"删除"（只有空卷可用，且作品至少保留一卷）
标题删除「第二卷 星渊」？
正文这一卷没有章节，删除后不能恢复。
按钮删除卷
调用volumes.remove(volumeId)；不满足条件时抛出 VALIDATION，提示条显示原因（入口按钮本应已禁用，这是兜底）
成功后提示条"已删除"，无撤销

5. 档案条目

入口S12 条目详情"⋯"菜单"删除条目"
标题删除「沈汐」？
正文条目和它的 2 条关系会移到回收站，30 天内可以恢复。正文不会改变。（没有关系时省略"和它的 N 条关系"）
有待审核变更指向它时追加："指向它的 1 条待审核变更将无法通过。"
提示：如果只是不再使用这个设定，可以改为"废弃"，它会保留在历史中。
按钮删除条目
调用entries.remove(entryId)
成功后返回 S11；提示条"已移到回收站"+"撤销"

6. AI 伙伴对话

入口S10b 对话列表左滑"删除"
标题删除对话「星海之镜的下落」？
正文对话内容删除后不能恢复。已经采纳或暂存到档案的设定不受影响。
按钮删除对话
调用该对话正在生成时先 conversations.stop，再 conversations.remove(id)
成功后提示条"已删除"，无撤销。删除的是当前对话时，S10 切换到最近的另一个对话；没有其他对话时显示空状态

7. 模型服务

入口S15a 模型服务操作"删除"、S02 编辑模式底部"删除这个服务"
标题删除模型服务「Claude」？
正文服务配置和保存在这台手机上的 API Key 会一起删除，不能恢复。服务商那边的 Key 不受影响。
是默认服务且还有其他服务时追加："删除后，「OpenAI」将成为默认服务。"（取剩余服务中最早创建的）
是最后一个服务时追加："删除后，AI 功能将不可用，直到你再连接一个模型服务。"
按钮删除服务
调用modelServices.remove(id)（按 G02 5.11.2 删除配置并清理 Key；返回 keyCleanupPending 时明确提示待清理）。排队中的定稿任务按 G04 绑定原服务快照，不自动改用其他服务：原服务已删除的任务进入 paused（no_service），作者在章节重新定稿预览后才会继续；没有服务时任务同样进入 paused（G02 第 6 节）
成功后从 S02 删除时返回 S15；提示条"已删除"，无撤销

8. 关系

入口S12b 关系编辑底部"删除这条关系"
标题删除这条关系？
正文"林宇 是 老周 的 徒弟"会被删除，不能恢复。如果关系只是在某一章结束了，可以改为设置"结束于第几章"。
按钮删除关系
调用relations.remove(id)
成功后关闭 S12b，回到 S12；提示条"已删除"

9. 验收要点

  • 每种对象的标题、正文、按钮文案与上表一致；删除按钮不是红色。
  • 作品、章节、条目删除后可以通过提示条撤销，也能在回收站恢复。
  • 删除默认服务后，正确的服务成为默认；删除最后一个服务后，AI 入口打开 D03。
  • 数据库删除失败时业务数据不变并显示错误；模型服务数据库删除成功但 Key 清理延迟时，必须报告已删除及待清理状态（G02 5.11.2）。
