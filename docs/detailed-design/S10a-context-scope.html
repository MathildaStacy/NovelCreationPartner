1. 页面功能

  • 在两种范围之间切换：全部已确认设定、仅某章相关（需选择章节）。
  • 列出这个范围下实际会带入的内容（作品信息、章节、对话记录、条目），每项显示状态徽标和估算 token，并显示合计与预算。
  • 超出预算时，标出哪些内容按优先级被去掉。
  • 开关"带入提议状态的条目"，默认开启，带入的提议标为"未确认"。
  • 保存为当前对话的参考范围，只影响之后发送的消息。

4. 数据与本地服务

打开弹窗

  • 初始值为 S10 传入的当前对话范围 PartnerScope = { kind, chapterId, includeProposed }（对话已有范围用保存值；空的新对话用默认值，规则 1）。
  • 调用 ai.previewContext(workId, scope, conversationId) 计算列表和合计（新增函数，定义见 S10 第 4 节）。只在本地计算，不调用模型，不需要网络和模型服务检查。
  • "选择章节"层调用 chapters.list(workId)。
  • 每次切换范围、章节或开关后重新调用 ai.previewContext（200 ms 防抖，后一次结果覆盖前一次）。

订阅事件

  • entries.changed、chapters.changed：弹窗打开期间重新计算。所选章节被删除时改回"全部已确认设定"，并在章节行位置提示"所选章节已删除"。

操作对应的服务

操作调用成功后失败时

5. 业务规则

  1. 默认范围（新对话）：kind = prefs.get('partnerScope')（默认 'confirmed'）；includeProposed = true；kind 为 'chapter' 时 chapterId 取最近编辑的章节（updatedAt 最新，含番外和草稿）。作品没有章节时退回 'confirmed'。修改默认值只影响之后新建的对话。
  2. 切到"仅某章相关"时的默认章节：上次在本对话选过的章节；没有则取最近编辑的章节。
  3. 两种范围带入的内容（组装逻辑以 G03 上下文组装为准，本页只负责展示）：
    • 全部已确认设定：作品信息、当前对话记录、作品中所有状态为已确认、正文已建立、有冲突的条目（只带这些状态的字段，附生效章节；有冲突的附冲突说明），以及最近 3 章的章节摘要。
    • 仅某章相关：作品信息、当前对话记录、所选章节的摘要（没有摘要时带入正文前 3000 字）、该章正文中提到的条目（entries.findMentions 按名称和别名匹配）、该章之前最近 2 章的摘要。条目字段按该章时的状态取值（entries.get(id, { atChapter })）。
    • 两种范围下，开关开启时都额外带入提议状态的条目（全部范围：作品中全部提议条目；章节范围：该章提到的提议条目），标为"未确认"。已废弃和已删除的条目不带入。
  4. 排序与截断优先级（从高到低，超出预算时从最低一级开始整项去掉，不截断单个条目）：
    优先级内容说明
    1作品信息书名、题材、一句话梗概、文风偏好，必带
    2最近 4 轮对话（8 条消息）必带
    3所选章节内容仅章节范围
    4已确认 / 正文已建立 / 有冲突的条目最近 4 轮对话中提到的排在最前；其余全部范围按类型（人物 → 世界观 → 规则 → 地点 → 势力 → 伏笔）再按更新时间倒序，章节范围按在该章出现次数倒序
    5章节摘要从近到远
    6更早的对话记录从近到远，按条去掉
    7提议条目（未确认）最先被去掉
  5. token 估算：与 G03 预算相同的方法，中文按字符数 ÷ 1.5 估算，向上取整。显示：小于 1000 显示整数（"320"）；1000 及以上以 k 为单位保留 1 位小数（"9.6k"）。合计前加"约"。
  6. 预算：默认 24k token（G03），取当前默认模型服务的设置；没有模型服务时按 24k 显示。系统提示和预留的输出长度不计入这里显示的合计。
  7. 范围按对话保存：每个对话有自己的范围。修改后只影响之后发送的消息；正在生成的回复继续使用原来的范围。
  8. 估算只用于展示和截断，实际 token 以模型服务返回的用量为准（见 S10e 查看详情）。
待确认：V1 是否允许在本页逐条排除某个条目（例如不想让 AI 看到某个伏笔）？当前设计不支持，只能整体切换范围和提议开关。

6. 边界情况

  • 作品信息和最近 4 轮对话本身就超过预算（例如对话里粘贴了很长的内容）：仍然带入这两项，其余全部不带入，说明改为"对话内容已接近预算，档案设定都没有带入。可以新建一个对话。"
  • 所选章节是空章节（0 字）：章节行显示"（空章节）"，只带入作品信息和对话，说明"这一章还没有正文"。
  • 弹窗打开期间在其他地方修改了档案：列表自动刷新；若此时已点"保存范围"，以保存时的范围为准，不影响结果。
  • 条目数量很多（≥ 500）：列表只渲染前 20 条直到点"显示全部"，展开后使用虚拟化列表。

7. 验收要点

  • 新建对话时，范围等于写作偏好中的默认范围；在 S15e 修改默认值后，已有对话的范围不变。
  • 切换到"仅某章相关"并选第 12 章，列表只出现第 12 章正文提到的条目；保存后 S10 上下文条显示"参考第 12 章与 N 条相关设定"。
  • 每个条目显示正确的状态徽标；提议条目显示"提议·未确认"，关闭开关后从列表消失、合计减少。
  • 构造超出 24k 的数据：出现超出预算说明，提议条目最先变为"未带入"。
  • 不修改直接关闭，范围不变；"保存范围"在没有修改时不可点。
  • 没有章节的作品中，"仅某章相关"置灰。
