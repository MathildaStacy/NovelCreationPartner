1. 元素与操作

#元素显示规则操作结果
1标题"更换「{书名}」的封面"；未命名作品为"更换封面"——
2"从相册选择"始终显示点击打开系统照片选择器（单选、仅图片）。选中后按第 2 节处理；在选择器中取消则什么都不做
3"换回文字书封"仅当前为图片封面时显示点击works.setCover(id, { kind: 'text' })，删除图片文件；提示条"已换回文字书封"
4"取消"始终显示点击关闭

V1 不提供拍照，也不提供裁剪界面：图片按 3:4 居中裁切显示。

2. 选图后的处理

  1. 使用系统照片选择器：iOS 为 PHPickerViewController，Android 为 Photo Picker（Android 13+ 原生，低版本由 Google Play 服务提供兼容版本）。两者都不需要相册权限，App 只拿到所选图片。实现建议 react-native-image-picker（launchImageLibrary，selectionLimit: 1，mediaType: 'photo'）。
  2. 调用 works.setCover(id, { kind: 'image', sourceUri })：复制到 App 沙盒 covers/{workId}.jpg，长边缩放到 1200px，JPEG 质量 0.85，去掉 EXIF（含位置信息）。
  3. 处理期间书封位置显示加载指示（超过 300 ms 才显示）。成功后提示条"封面已更换"。

3. 异常

情况处理
格式不支持（如 HEIC 在少数 Android 设备无法解码、GIF 动图）提示条"这张图片无法使用，请换一张 JPG 或 PNG 图片"。GIF 取第一帧
原图大于 30 MB提示条"图片太大，请换一张小于 30 MB 的图片"
来自 iCloud 且未下载系统选择器负责下载；超时或失败时提示条"图片没有读取成功，请稍后重试"
存储空间不足STORAGE_FULL，按 G02 错误码处理，封面保持不变

4. 验收要点

  • 两个平台选图都不弹出相册权限请求。
  • 换封面后书架立即显示新图，没有题签、保留书脊；换回文字书封后图片文件被删除。
  • 保存的封面文件中没有 GPS 等 EXIF 信息。
