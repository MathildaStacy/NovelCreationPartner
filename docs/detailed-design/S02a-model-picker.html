1. 页面功能

  • 用 S02 当前的草稿（协议、Base URL、鉴权头、API Key，不必先保存）请求服务的模型列表。
  • 一个输入框同时用于搜索和手填：输入内容在列表中没有完全相同的项时，顶部出现"使用「…」作为模型名"。
  • 显示最近用过的模型（本机保存过的服务用过的模型，按协议过滤），列表拿不到时也能从这里选。
  • 默认隐藏向量、语音、图像等不能用于写作的模型，可一键显示全部。
  • 列表拿不到（服务没有列表接口、Key 错误、网络问题）时说明原因，手填仍然可用。

4. 数据与本地服务

传入（组件属性，不经导航参数）

  • S02 的草稿 draft（协议、Base URL、options.authHeader、id）、Key 输入框内容 keyInput、当前模型名、模型列表缓存。
  • 本页做成 S02 内部的模态组件而不是路由，是因为 S02 规则 5 不允许把 Key 放进导航参数。

进入页面（并行）

  • prefs.get('recentModels')：最近使用（G02 5.12）。
  • 缓存命中（规则 6）时直接显示缓存列表；否则 modelServices.fetchModels(draft, key) → string[]。key 取 keyInput；编辑模式且输入框为空时传 undefined，由服务层读取已保存的 Key（与 S02 测试相同）。

操作对应的服务

操作调用成功后

选中模型无（只改 S02 草稿）关闭本页，回填 S02

5. 业务规则

  1. 请求地址：modelServices.resolveUrl(protocol, baseUrl, 'models')，GET；鉴权头与生成请求相同（G03 2.2）。Anthropic 分页最多 5 页（G03 6.2），超出部分不显示，也不提示。
  2. 排序：服务返回的模型按 ID 排序，使用数字感知的字母顺序（Intl.Collator('en', { numeric: true, sensitivity: 'base' })），例如 claude-sonnet-4-5 在 claude-sonnet-5 前面。G03 已去重。
  3. 搜索：输入和模型 ID 都先转小写，再去掉空格、-、_、.，然后做包含匹配。所以 "sonnet 5"、"Sonnet5" 都能匹配 claude-sonnet-5-5。"使用「…」"按钮的完全相同判断不做这层处理，区分大小写。
  4. 隐藏非文本模型：模型 ID 转小写后包含以下任一片段即隐藏：embed、tts、whisper、transcribe、dall-e、gpt-image、moderation、realtime、audio。只影响列表显示；手填和"最近使用"不受影响。
  5. 选中：把模型名写入 S02 草稿的 model 并关闭本页。值与原来不同时，按 S02 规则 11 清空 caps，并清空测试结果区（S02c）；值相同时什么都不变。模型名的长度校验（1–200 个字符）由 S02 保存时统一执行。
  6. 缓存：成功获取的列表存在 S02 页面内存中，键为"协议 + 模型列表地址 + 鉴权头 + Key 输入框内容是否为空 + Key 输入框内容的哈希"。10 分钟内再次打开且键相同，直接用缓存，不发请求。协议、Base URL、鉴权头或 Key 改动后缓存失效。离开 S02 后缓存丢弃。
  7. 超时：列表请求 20 秒没有完成即按 AI_TIMEOUT 处理（与连接测试的总超时一致）。不自动重试。
  8. Key 安全：请求只发往规则 1 的地址，不跟随跨域名重定向（S02 规则 10）。

6. 边界情况

  • S02 模型输入框已有值、但列表和最近使用里都没有：输入框为空时，"最近使用"分组顶部多一行该值，带"当前"徽标和"不在列表中"，点它等于不改动直接关闭。
  • 服务返回 5000 个模型（Anthropic 5 页上限）：列表用 FlatList 虚拟化，过滤在每次输入后同步完成；超过 1000 项时输入防抖 150 ms。
  • 加载中用户已手填并选中：中止请求，按选中处理。
  • 加载中切到后台再回来：请求若已被系统中止，显示"获取失败"状态，可点"重试"。
  • 列表返回后与"最近使用"有重复：两组都显示，不合并。
  • 模型 ID 含中文或空格（少数中转服务）：照常显示和搜索；选中后原样回填。
  • 编辑模式下 Key 输入框为空、服务 hasKey = false：S02 会先报"请填写 API Key"，不会打开本页。

7. 验收要点

  • OpenAI 官方地址 + 有效 Key：列表出现，默认不显示 text-embedding-*、tts-*、whisper-*；点"显示全部"后出现。
  • 输入 "sonnet 5" 能找到 claude-sonnet-5-5；输入列表中没有的名字时出现"使用「…」作为模型名"，点后回填到 S02。
  • 选中与原值不同的模型后，S02 的测试结果区清空；选中相同模型时结果区保留。
  • 不提供 /models 的中转服务：显示"这个服务没有提供模型列表…"，输入框自动聚焦，可手填。
  • Key 错误时显示"API Key 无效或已失效。"，点"回去修改 Key"回到 S02 且 Key 输入框获得焦点。
  • 10 分钟内关闭再打开不重复请求；改了 Base URL 后再打开会重新请求。
  • 保存过一个服务后，新建另一个同协议服务时，"最近使用"里出现刚才的模型。
  • 断网时打开：显示"连不上 {域名}…"，"最近使用"和手填仍可用。
