1. 页面功能

  • 列出模型服务并提供添加入口；每个服务的操作见 S15a。
  • 作为写作偏好、导出、恢复、回收站、AI 数据说明、关于的入口，并显示各项摘要与本地存储占用。

4. 数据与本地服务

  • 服务列表：modelServices.list()，订阅 services.changed。
  • 写作偏好摘要：prefs.get（editorFont、editorFontSize、candidateCount），订阅 prefs.changed。
  • 回收站项数：trash.list().length；存储占用：storage.usage()（db + covers + cache 之和，按 MB 保留 1 位小数）。两者在页面获得焦点时重新读取。

5. 业务规则

  1. 本页不直接修改数据，所有写操作都在子页面或 S15a 中完成。
  2. 没有账号、登录、云同步入口；备份只能通过 S15b 导出文件、S15c 导入文件完成。
  3. API Key 不在本页显示，也不能从任何设置项导出。通过 modelServices.hasPendingKeyCleanup() 查询补偿状态；存在待清理项时在服务区提示「本机 Key 待清理，解锁后返回应用会继续」，随 services.changed/页面焦点刷新。

6. 边界情况

  • 从子页面返回时（如恢复了作品、清空了回收站、改了偏好），摘要与存储占用随事件或获得焦点刷新。
  • 服务很多（10 个以上）：列表整体随页面滚动，不单独限高。

7. 验收要点

  • 9 个元素都能进入对应页面或菜单。
  • 写作偏好摘要、回收站项数、存储占用在相关操作后返回本页即更新。
  • 本页没有登录、账号或直接显示 API Key 的入口；S02 编辑页允许作者主动显隐（G02 5.11）。
