1. 页面功能

  • 按六个分类（人物、世界观、地点、势力、规则、伏笔）列出条目，分类标签显示数量，可横向滚动。
  • 按状态筛选：全部、提议、有冲突、已废弃，每项带计数；默认隐藏已废弃条目。
  • 跨分类搜索条目名称、别名、摘要和字段内容。
  • 每个条目显示名称、状态徽标、一行摘要、来源说明，有待审核变更时显示小标记；伏笔额外显示"已回收 / 未回收"。
  • 进入条目详情；添加条目（类型预设为当前分类）。
  • 每个分类在没有条目时给出引导文案和入口。

4. 数据与本地服务

进入页面

  • 调用 entries.counts(workId)，得到分类数量和各分类的状态数量。
  • 调用 entries.list(workId, { type }) 读取当前分类（默认人物；从 S05 进入时用传入的分类）。
需要修改：entries.counts(workId) 的 byState 需要按分类返回，即 byState: Record<EntryType, Record<MemoryState, number>> —— 状态筛选的计数是"当前分类内"的数量。
需要修改：EntryListItem 需要明确包含 type、pendingCount（待审核提案数）、sourceLabel 与 sourceAt，伏笔另含 resolved: boolean 和 resolvedChapterId: ID | null；entries.search 的结果包含已废弃条目（排在最后）。

订阅事件

  • entries.changed：重新读取计数和当前列表（保留滚动位置）；搜索模式下重新执行当前搜索。
  • proposals.changed：刷新待审核小标记。
  • conflicts.changed：刷新状态徽标和"有冲突"计数。
  • chapters.changed：人物按首次出场排序、伏笔回收章节编号可能变化，重新读取当前列表。

5. 业务规则

  1. 默认分类：人物。从 S05 档案速览进入时使用传入的分类。作品内切换标签后回来，保留上次的分类、筛选和滚动位置；退出作品再进入时回到默认。
  2. 筛选：只按条目状态（不是字段状态）筛选。"全部"= 提议 + 已确认 + 正文已建立 + 有冲突，不含已废弃；"提议"只含整条仍是提议的条目（例如 AI 伙伴"暂存"的条目），已确认条目里个别字段的提议不计入。
  3. 排序：按 entries.list 的结果顺序——名称拼音排序；人物按首次出场章节排序，没有出场的人物排在后面再按拼音排序。界面不另外排序。
  4. 摘要行：显示一行摘要，最多 1 行，超出以省略号截断。没有摘要时显示模板中第一个已填写字段，格式"身份：渔村少年"；都没有填写时不显示这一行。
  5. 来源说明：按条目的来源显示："手动添加""AI 伙伴采纳""AI 伙伴暂存"（来源为 AI 伙伴且条目仍是提议时）"第 N 章审核"（N 为当前编号，章节已删除时为"已删除的章节审核"）"AI 补全"，后接最后修改时间。
  6. 待审核小标记：N 为该条目待审核提案数（status = 'pending'）；超过 9 显示"9+"。
  7. 伏笔回收标记：取伏笔字段"是否已回收"的当前值；没有该字段时视为"未回收"。回收章节编号用 chapters.numberOf 换算（G02 4.4）。
  8. 搜索：去掉首尾空白后为空时不搜索；关键词最多 30 字，超出部分不参与搜索。搜索不受分类和状态筛选限制，覆盖全部分类；已废弃条目排在最后。结果最多显示 100 条，底部显示"只显示前 100 条，请输入更具体的关键词"。
  9. 数量格式：见 G01 数字。
  10. 回收站中的条目在本页任何位置都不出现。

6. 边界情况

  • 当前停留在"已废弃"筛选时，最后一个已废弃条目被恢复：数量变为 0，筛选自动回到"全部"。
  • 后台任务（记忆提取、冲突检测）在作者浏览时写入新数据：通过事件刷新，滚动位置不变；新出现的"有冲突"条目不打断当前操作。
  • 名称很长（30 字）：第一行名称截断，状态徽标和伏笔回收标记始终完整显示。
  • 条目很多（≥ 500 个）：列表使用虚拟化（FlatList），计数仍按全部条目计算。
  • 从 S12 删除条目后返回：列表已通过事件刷新，提示条"已移到回收站"由 S12 发起，返回后仍可点"撤销"（见 S12）。
  • 搜索时切到其他标签再回来：仍停留在搜索模式和原关键词。

7. 验收要点

  • 新建作品后进入档案，人物分类显示空状态文案"还没有人物。添加主角，或在 AI 伙伴里讨论后采纳。"和"添加人物"。
  • 在伏笔分类点"添加条目"，S12a 的类型预设为伏笔。
  • 分类标签上的数量与列表一致，且不含已废弃条目；状态筛选的计数只统计当前分类。
  • 废弃一个条目后，它从"全部"中消失、出现在"已废弃"中；恢复后回到"全部"。
  • 有待审核变更的条目显示"● 待审核 N"；在 S13 处理完后标记消失。
  • 伏笔在 S12 标记为已回收后，列表显示"已回收 · 第 N 章"；调整章节顺序后 N 随之变化。
  • 搜索"星"能同时找到人物、规则、世界观、伏笔中的相关条目，并标出分类；按别名也能搜到。
  • 从 S05 档案速览点伏笔，进入后直接停在伏笔分类。
  • 切换到其他标签再回来，分类、筛选和滚动位置不变。
