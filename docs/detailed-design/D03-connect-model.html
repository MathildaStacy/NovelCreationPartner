先连接一个模型服务1

AI 伙伴、描写助手和定稿后的整理需要连接模型服务。支持 OpenAI Responses 和 Anthropic Messages 两种协议，填写你自己的地址和 API Key 即可。2

不连接也可以正常写作和整理档案。

连接模型3
不用 AI，继续写4

1. 功能

  • 情况 A：没有任何模型服务（modelServices.getDefault() 为 null）。
  • 情况 B：本任务实际绑定的服务缺少 Key（hasKey = false，通常是从备份恢复后）。
  • 去连接或填写 Key，完成后回到原页面并保留草稿；作者再点一次才继续，不自动续发（第 3 节，2026-10-19 作者确认）。

2. 元素与操作

#元素显示规则操作结果 / 去向
1标题A："先连接一个模型服务"；B："需要填写 API Key"——
2说明A：如线框。B："「Claude」缺少 API Key，填写后才能使用。"——
3主按钮A："连接模型"；B："填写 Key"点击关闭弹窗。A：进入 S02 引导模式；B：进入 S02 编辑该服务，焦点在 API Key 输入框
4"不用 AI，继续写"始终显示；下滑、点遮罩、Android 返回键等同点击关闭弹窗，留在原页面，原操作不执行。从 S04"开始构思"进入时，改为只创建作品并进入 S05

3. 返回与继续

  1. 打开弹窗时，界面层统一入口 useAiAction() 暂存"待继续的操作"（一个闭包，含原参数）。
  2. 在 S02 保存成功后导航返回原页面并保留草稿。作者重新点击预览时，按本任务绑定重新解析服务、核对 Key 并生成新 ContextPlan，再经过 G03 数据说明；不自动续发先前操作。原页面已不存在时不恢复操作。
  3. 在 S02 点"稍后再说"或返回：回到原页面，丢弃该操作，不提示。
  4. 后台任务保留入队时的服务和输入快照；连接新服务不自动绑定或重放旧任务。缺少服务、旧输入或过期计划需作者重新确认定稿；中断请求需明确确认可能再次计费。

4. 数据与本地服务

判断：taskServices.getTaskService(route)（前台创作入口为 writing）；仅未显式绑定时沿用默认。为 null 时情况 A，实际绑定服务 hasKey = false 时情况 B；损坏绑定明确要求在设置重新选择，不改发默认服务。填写 Key 打开实际绑定的 serviceId。本弹窗本身不写数据。

5. 验收要点

  • 没有模型服务时点描写助手，出现本弹窗；连接成功后回到编辑器保留正文，再次点击可打开描写助手；不会自动发送。
  • 点"不用 AI，继续写"后留在原页，没有任何请求。
  • 从备份恢复后，点 AI 功能出现"需要填写 API Key"，填写后可用。
  • 新建作品时选择"不用 AI，继续写"，作品已创建并进入概览。
