1. 页面功能

  • 作品信息头卡：顶部 4pt 题材色带；书名、连载状态徽标、"{题材} · 正文 N / 计划 M 章 · {字数}"、一句话灵感（最多 2 行）。
  • 继续写作：最近编辑的章节标题、最后编辑时间、最后一段前 60 字，点击进入 S07 编辑器并恢复上次光标位置；没有章节时显示"＋ 新建第一章"。
  • 待处理：未处理的设定冲突、待审核记忆、进行中或失败的后台任务；三项都为 0 时整组隐藏。
  • 故事档案速览：人物数、世界与设定数、未回收伏笔数。

4. 数据与本地服务

  • 进入作品时（由 S03 / S03b 调用）works.touch(workId)；本页进入和重新获得焦点时调用 works.overview(workId)，取章节数、总字数、计划章数、最近编辑章节及最后一段前 60 字、待处理计数与任务、档案计数（G02 5.1）。
  • 订阅 work.updated、chapters.changed、entries.changed、proposals.changed、conflicts.changed、jobs.changed（同一 workId），收到后 300 ms 内合并为一次 works.overview 刷新。
  • 收到 work.removed（本作品）时返回书架。

5. 业务规则

  1. "最近编辑的章节"取 updatedAt 最大的未删除章节，包含番外和草稿；标题前缀按 G02 4.4（正文"第 N 章"，番外和草稿只显示标题）。
  2. 最后编辑时间按 G01 时间格式（今天 14:32 / 昨天 / 10月3日）。
  3. 章节数只统计正文（kind = 'main'）；字数统计所有未删除章节。
  4. "未回收伏笔"指类型为伏笔且状态未回收的有效条目；待审核提案不计入任何档案计数。
  5. 任务完成后若产生新的待审核提案或冲突，在本页底部显示一次提示条（G02 第 6 节第 9 条）。

6. 边界情况

  • 最近编辑的章节被删除：改取下一章；全部删除后显示"＋ 新建第一章"。
  • 最后一段为空或只有空白：预览取前一个非空段落；正文为空时预览显示"还没有正文"。
  • 在 S05a 修改题材：返回后色带颜色立即变化。
  • 后台任务在本页停留时完成：任务行和待审核计数实时更新，无需下拉刷新。

7. 验收要点

  • 新建尚无章节的作品进入 S05，"继续写作"为"＋ 新建第一章"，点击可创建第一章并进入编辑器。
  • 冲突数、待审核数、进行中和失败任务均为 0 时，"待处理"整组不显示。
  • 定稿一章后回到概览，任务行显示"正在整理第 N 章（k/3）"并随进度变化，完成后出现待审核行。
  • 在 S05a 修改文风偏好并保存后，S08 描写助手与 S10 AI 伙伴的请求均带上该文风。
  • "‹ 书架"返回书架，该作品排在第一位。
