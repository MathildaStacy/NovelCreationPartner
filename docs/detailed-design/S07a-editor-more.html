1. 页面功能

  • 在不离开编辑器的前提下，提供 5 个本章操作：章节信息、版本历史、存为版本、导出本章、字体与字号。
  • 标题行显示章节编号、标题、字数和状态，作为本章的字数统计（字数口径同 G01 数字与字数格式）。
  • 不提供"定稿本章"：定稿是本章主流程操作，固定在底部工具栏，避免两处入口状态不一致。

2. 元素与操作

#元素显示规则操作结果 / 去向
1标题行正文章节："第 N 章 {标题} · {字数} 字 · {状态}"，状态为 草稿 / 已定稿 / 有修改未定稿；番外、草稿章节："{标题} · {字数} 字 · 番外"（或"草稿"）。标题超过 12 字截断加"…"。字数取编辑器当前值（含尚未落盘的输入）不可点—
2"章节信息"始终显示点击关闭操作表，打开 S06a 章节信息（编辑模式，可改标题、类型、所属卷）。不需要先保存正文。保存后编辑器标题、状态行随 chapters.changed 更新
3"版本历史"始终显示点击先立即保存；成功后压入 S07d 版本历史。保存失败：提示条"正文没有保存成功，暂时不能查看版本历史。"
4"存为版本"始终显示；正文为空（0 字）时置灰点击先立即保存；成功后调用 versions.snapshot(chapterId, 'manual')。新建快照：提示条"已存为版本"，右侧"查看"→ S07d。正文与最近一个快照相同（服务直接返回已有快照）：提示条"内容没有变化，未新建版本"。置灰时点击提示"正文为空，没有可保存的版本"
5"导出本章"只对正文章节和番外显示；草稿章节不显示（backup.exportText 不导出草稿）。正文为空时置灰点击先立即保存；成功后压入 S15b 导出，预选"导出正文"、本作品、仅勾选本章、格式沿用上次选择（默认 TXT）
6"字体与字号"始终显示点击关闭操作表，升起图②的二级弹窗
7"取消"（仅 iOS）始终显示点击 / 点遮罩 / 返回键关闭操作表，键盘不自动恢复，光标位置不变
8正文字体宋体（serif，默认）/ 黑体（sans）点击prefs.set('editorFont', v)，正文立即重排
9字号小 16 / 中 18（默认）/ 大 20点击prefs.set('editorFontSize', v)，正文立即重排，光标所在行保持在可见区域
10"完成"始终显示点击 / 下滑 / 点上方正文区关闭弹窗。设置已即时保存，无需确认；与 S15e 写作偏好为同一组偏好

4. 数据与本地服务

时机调用说明

5. 业务规则

  1. 打开操作表时收起键盘；操作表、二级弹窗都不算离开编辑器，不生成 auto 快照（S07 第 5 节）。
  2. "版本历史""存为版本""导出本章"依赖数据库中的正文，必须先立即保存成功；"章节信息""字体与字号"不依赖正文，直接执行。
  3. "存为版本"连续点击：第二次时正文未变，返回已有快照，提示"内容没有变化，未新建版本"，不会产生重复快照。
  4. "导出本章"依赖 S15b（P1）。S15b 未完成的版本中隐藏此项，其余 4 项不受影响。
  5. 字体、字号是全局偏好，对所有作品的编辑器生效，不按章节保存。
  6. 已定稿或有修改未定稿的正文章节在 S06a 改为番外或草稿会被拒绝（G02 chapters.update 抛 VALIDATION），需先在 S06b 章节操作中"撤销定稿"；S06a 负责显示该错误。

6. 边界情况

  • 操作表打开期间后台冲突检测完成：操作表不受影响，关闭后编辑器冲突提示条出现。
  • 操作表打开时 App 进入后台：照常立即保存；回到前台时操作表仍在。
  • 在 S06a 改了标题后返回：操作表已关闭，顶栏标题立即更新。
  • 本章在其他入口（如 S06 长按）被删除后又在编辑器打开操作表：不会出现，因为删除时编辑器已退出。
  • 章节字数超过 2 万字：标题行字数照常显示，不额外提示（长章节提示在 S07 状态行下方）。

7. 验收要点

  • 点"⋯"弹出操作表，标题行字数与状态行一致，包括刚输入、尚未自动保存的文字。
  • "存为版本"后进入 S07d，最上方出现来源为"手动"的版本；不改正文再点一次，提示"内容没有变化，未新建版本"。
  • 断开数据库写入（模拟保存失败）时点"版本历史"，不跳转并显示对应提示条。
  • 切换字号，正文立即变化，光标位置不变；去 S15e 看到相同的选中值。
  • 草稿章节的操作表没有"导出本章"；正文章节点"导出本章"进入 S15b 时只勾选本章。
