1. 页面功能

  • 全部作品备份：backup.exportAll()，生成一个 .ncpbak 文件，包含全部未删除作品及模型服务的非敏感配置，可在任何装有本 App 的手机上用 S15c 恢复。
  • 单部作品备份：backup.exportWork(workId)，只含一部作品，不含模型服务。
  • 导出正文：backup.exportText(workId, { chapterIds?, format })，按作品导出 TXT 或 Markdown，只含正文（可选番外），用于发布或在电脑上阅读，不能用于恢复。
  • 生成后交给 D07 系统分享面板；本页不提供"保存到某目录"之类的自选路径（iOS 分享面板内含"存储到'文件'"）。

5. 业务规则

  1. 完整备份包含：manifest.json（格式版本 1、App 版本、导出时间、作品清单）、data.json（作品、卷、章节含草稿和番外、全部历史版本、档案条目与字段历史、关系、AI 伙伴对话、记忆提案、冲突、灵感）、covers/ 封面图片；全部作品备份另含模型服务的名称、协议、地址、模型和选项。
  2. 完整备份不包含：API Key（Key 只在 iOS Keychain / Android Keystore，backup 不能调用 secure.getKey）、回收站中的内容、后台任务队列、偏好设置（prefs）、AI 数据说明确认记录。
  3. 导出正文：只含正文章节（可选番外），不含草稿、档案、版本、对话；TXT 每章以"第 N 章 标题"作分隔行（番外为"番外 标题"），Markdown 以 ## 第 N 章 标题 二级标题、文件首行 # 书名；每段前加两个全角空格（与 S07 显示和复制效果一致），段间一个换行，空段保留；UTF-8 带 BOM。
  4. 导出不改数据：只读操作，不写数据库、不发事件、不涉及网络。离线可用。
  5. 生成期间锁定：同一时间只生成一个文件；生成中禁用返回，切到后台不打断（回到前台后继续等待结果）。生成完成前 App 被杀：不留下半个文件以外的影响，临时文件下次启动清理。
  6. 预选只填默认值：从 S03a / S06b / S07a 进入时预选的模式、作品、章节可以随意改。

6. 边界情况

  • 作品没有正文章节：导出正文的主按钮置灰，说明"这部作品还没有正文章节"；单部备份仍可导出（包含灵感和档案）。
  • 选中章节在本页打开期间被删除：服务层会剔除已删除章节；若剩 0 章，抛 VALIDATION，页内红字"所选章节已被删除，请重新选择"。
  • 作品很大（数百章、几十张封面）：生成可能需要数十秒，按"生成中"处理，不设超时。
  • 书名含 / : ? 等字符或超长：文件名按 D07 第 2 节替换和截断。
  • 设备锁屏或 Keychain 不可用不影响导出（导出不读 Key）。

7. 验收要点

  • 三种入口分别预选正确的模式、作品和章节。
  • 解压全部作品备份，manifest.json 格式版本为 1；data.json 中搜索已保存的 Key 字符串，结果为 0；不含回收站中的作品。
  • 单部备份只含该作品，没有模型服务。
  • TXT 在 Windows 记事本中不乱码，章节按编号排序、每段段首两个全角空格；Markdown 标题层级正确；草稿章节不出现。
  • 生成中不能返回；存储不足时显示指定文案且不打开分享面板；iOS 关闭分享面板不提示、完成显示"已导出"；Android 仅提示"已打开系统分享"，不推断目标保存结果。
  • 飞行模式下三种导出均可完成。

8. 2026-10-18 实现记录与验证边界

当前交付为设置内 ExportSheet 与作品/章节来源的 ExportScreen。特性层 backup.build(workId?) → Uint8Array 在同一只读事务中生成格式版本 1 的 manifest.json / data.json，单部模式不附带服务；backup.exportText(workId,{format,chapterIds?}) 返回 UTF-8 BOM 正文。默认正文范围为 main，显式章节 ID 可包含番外，始终排除草稿；Markdown 书名使用一级标题，无可导出章节时报 VALIDATION。

  • 完整备份包含未删除作品、卷、章节、版本、档案与字段历史、有效关系、对话、提案、冲突及当前仍可安全撤销的采纳收据。作者在采纳后改过档案而已失效的撤销收据不会被恢复为有效；恢复完整重映射 ID 后重新绑定仍有效收据。
  • 不导出 Key、Key 状态、服务测试结果、错误诊断、任务队列、偏好、AI 确认记录、用量账本、请求缓存或运行时提案审计。服务选项逐字段白名单重建，非标准嵌套选项不随文件流出；从不调用 secure.getKey。没有可恢复的付费任务。字段或关系历史若仍以回收站章节为生效端点，会明确停止完整备份并提示先恢复/核对相关章节；不会把缺失端点变为无界区间。
  • 压缩文件与 JSON / 封面附件解压总计均限制 50 MiB。恢复只接受固定 JSON 文件名和 covers/UUID.jpg 附件、格式及表白名单，重复 ZIP 项、额外路径、宣称超限体积及跨作品引用均拒绝。导出/恢复全程离线。
  • 图片封面附件：从不可变私有 token 读取 JPEG，以 covers/UUID.jpg 和 data.coverAssets（所属作品、路径、MIME）打包；works 的设备路径与 token 均置 null，不泄漏原设备文件位置。附件须一作品一份、完整且无额外项、单张≤30 MiB、JPEG 结构与正尺寸有效、长边≤1200。旧设备任意路径且没有安全 token 时明确拒绝，要求重新选择封面；并发删除或损坏文件不生成遗漏封面的“完整”备份。
  • 文件交付已有 Android SAF / FileProvider 系统选择和分享、iOS UIDocumentPicker / UIActivityViewController 原生端口，JS 边界只传安全名称及有界内容，不接受任意路径。Android 编译与文件端口自动测试通过；iOS 缺完整 Xcode SDK，尚未编译/设备实测。分享取消/成功、云盘、平板、前后台及接近上限的系统行为仍需真机验证，详见 原生文件验证记录。

当前设置入口可导出全部/单部备份和单部正文；正文支持选择章节、包含番外与从作品/章节入口预选。生成时锁定选择、重复点击与页面返回，UI 经 features/backupFiles 交付，避免跨层处理编码或原生文件。导出无作品/无章节时禁用。原生返回 completed/cancelled/opened，iOS 完成与取消、Android 仅 chooser 打开分别反馈；文件按作品/章节命名，总长≤80 Unicode 字符且保留扩展名，ENOSPC/EDQUOT 映射指定存储不足文案。启动独立清理旧进程导出文件，失败记录后继续其他恢复步骤；不以本地单元测试替代设备验证。
