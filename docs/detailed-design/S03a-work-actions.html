1. 页面功能

  • 针对被长按的这一部作品，提供 6 个操作：打开、编辑作品信息、更换封面、切换连载状态、导出、删除。
  • 标记状态和删除在书架原地完成，提示条提供 5 秒"撤销"。
  • 编辑信息、换封面、导出、删除分别交给 S05a、D06、S15b、D02，本菜单只负责分发。

4. 数据与本地服务

入参：S03 / S03b 传入被长按作品的 WorkSummary（id、title、genre、status、chapterCount、cover）。本菜单不订阅事件，关闭即销毁。

操作调用成功后
打开works.touch(id)（不等待）进入 S05
标记状态works.update(id, { status: 'finished' | 'ongoing' })发出 work.updated，S03 重新调用 works.list()：筛选计数变化；当前筛选为"连载中"或"已完结"时该书从网格中移出（淡出 200 ms）
撤销标记works.update(id, { status: 原值 })同上，书回到原位置（按排序规则，可能排到第一位，见第 5 节第 3 条）
删除在 D02 中调用 works.remove(id)发出 work.removed；书从网格移出。该作品排队中的后台任务暂停（G02 works.remove）
撤销删除trash.restore('work', id)作品回到书架原位置（updatedAt 不变）
编辑信息 / 换封面 / 导出由 S05a、D06（works.setCover）、S15b（backup.exportWork）调用书架通过 work.updated 或重新获得焦点刷新

5. 业务规则

  1. 菜单项顺序固定为：打开、编辑作品信息、更换封面、标记状态、导出这部作品、删除作品。不因作品状态增减项目，只有第 4 项文案随状态变化。
  2. 长按判定：按住 500 ms 且手指移动不超过 10 pt；超过 10 pt 视为滚动，不弹菜单。菜单打开期间书架不响应滚动。
  3. 标记状态会更新 updatedAt，作品因此排到书架第一位（见 S03 第 5 节的待确认项）。撤销后 updatedAt 再次更新，不恢复原来的时间。
  4. 删除走回收站：只写 deletedAt，30 天内可在提示条撤销或到 S15d 回收站恢复，30 天后启动时彻底删除（G02 4.1）。
  5. 提示条撤销只对最近一次操作有效：5 秒内再次标记或删除另一部作品时，前一个提示条被替换，前一次操作不再能从提示条撤销（删除仍可在回收站恢复）。
  6. 标记为已完结不限制任何编辑：已完结的作品仍可写正文、定稿、使用 AI。

6. 边界情况

  • 在"已完结"筛选下把最后一部作品标记为连载中：网格变空，显示 S03"筛选下无作品"状态；提示条的"撤销"仍可用。
  • 删除后书架没有作品了：显示空书架；提示条"撤销"仍可用，撤销后恢复正常网格。
  • 删除的作品有正在运行的后台任务：任务被中止并暂停；撤销删除后任务继续排队。
  • 菜单打开时 App 进入后台：菜单保持；回来后操作仍针对同一部作品。
  • 从 S03b 搜索结果长按：菜单相同；删除或标记成功后搜索结果按同一查询重新查询。
  • 快速连续长按两本书：只有第一次长按弹出菜单，菜单打开期间其他长按无效。

7. 验收要点

  • 长按书封 500 ms 有触觉反馈并弹出菜单；按住拖动不会弹出。
  • 连载中的作品显示"标记为已完结"，已完结的作品显示"标记为连载中"；点击后筛选计数立即变化，"撤销"能恢复。
  • "编辑作品信息"保存后回到书架，书名和题签已更新，没有进入作品。
  • "更换封面"在菜单完全收起后才出现 D06，两个操作表不重叠。
  • "导出这部作品"进入 S15b 时已选中单部作品备份和该作品。
  • "删除作品"文字不是红色；确认后书从书架消失，提示条"撤销"能恢复，回收站里也能看到它。
  • 读屏用户通过"更多操作"打开同一菜单，焦点在标题行。
