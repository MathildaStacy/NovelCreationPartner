1. 页面功能

  • 列出回收站中的作品、章节、档案条目（trash.list()），按类型筛选，显示所属作品、删除时间、剩余天数。
  • 恢复单项（trash.restore(kind, id)）、彻底删除单项（trash.purge(kind, id)）、清空回收站（trash.empty()）。彻底删除和清空不可撤销，需确认。
  • 卷、AI 对话、模型服务、关系等不进回收站（直接删除，见 D02），不出现在这里；随条目一起删除的关系随条目恢复，不单独列出。
2026-10-19 实施同步：每行右侧保留可见“恢复”；“彻底删除”改为左滑露出（错误色）或长按操作表“恢复 / 彻底删除 / 取消”，仍经确认对话框。恢复成功提示条为“已恢复「名称」”+“查看”（作品 → S05、章节 → S06、条目 → S12）。行操作使用公共 components/SwipeRow（PanResponder，无新增原生依赖）：只接管明显横向的拖动，纵向交给列表；同一列表同一时间只展开一行，滚动列表或点任意行先收起；收起中的按钮立即不可点并对读屏隐藏，动画结束后卸载；减弱动态效果时直接到位。读屏用户通过 accessibilityActions 获得同样的操作，不依赖手势。恢复章节放入第一卷时的“（已放入「卷名」）”后缀尚未实现；真机手势与两端触控仍待设备验收。

4. 数据与本地服务

  • 列表：trash.list() → TrashItem[]（作品、章节、条目，含所属作品、删除时间、剩余天数）。订阅 work.*、chapters.changed、entries.changed，页面获得焦点时也重新读取。
  • 恢复：trash.restore(kind, id)，清除 deleted_at；发出对应 *.changed。
  • 彻底删除：trash.purge(kind, id)；作品级联删除卷、章节、版本、条目、关系、对话、提案、冲突、任务和封面文件（G02 4.1）。
  • 清空：trash.empty()，等同对全部项 purge，一个事务。
  • 剩余天数 = 30 − 删除后已过整天数（向上取整，最小 1）。自动清理在启动流程第 2 步（G02 第 10 节），本页不做定时清理。

5. 业务规则

  1. 保留期：30 天，固定，不可设置。
  2. 恢复：
    • 作品：连同随它一起删除的章节、条目一并恢复（G02 只写作品的 deleted_at，子项本来就随作品隐藏）；在作品删除前已单独删除的章节、条目仍留在回收站。
    • 章节、条目：所属作品也在回收站时，先弹对话框"所属作品「{书名}」也在回收站中，需要一并恢复。"按钮"取消 / 一并恢复"；确认后先恢复作品再恢复该项。
    • 章节原卷已删除时放入作品第一卷末尾，提示条追加"（已放入「{卷名}」）"；正文章节编号按 G02 4.4 重新计算。
    • 条目恢复时一并恢复删除时随它删除的关系（G02 5.5 entries.remove）。
    • 恢复后与现有对象重名（例如删除后又新建了同名条目）：仍然恢复，不改名；档案中同名提醒按 S11 现有规则显示。
  3. 彻底删除确认：沿用 D02 通用样式，标题"彻底删除「{名称}」？"；正文"彻底删除后无法恢复。"作品追加"作品的全部章节、档案、对话和封面都会一并删除。"；按钮"取消 / 彻底删除"（红色）。
  4. 清空确认：标题"清空回收站？"；正文"回收站中的 {N} 项将被彻底删除，无法恢复。"；按钮"取消 / 清空"（红色）。
  5. 不可撤销：彻底删除和清空后的提示条没有"撤销"。已导出的备份不受影响。
  6. 存储空间：彻底删除后 S15 的本地存储占用随 storage.usage() 更新（返回 S15 时重新读取）。

6. 边界情况

  • 页面打开期间跨过保留期：不在本页清理，下次启动时清理；剩余天数最小显示"还剩 1 天"。
  • 同时有大量项（数百章）：列表虚拟滚动；清空一次事务完成，期间遮罩。
  • 恢复章节时作品已被彻底删除（另一入口并发操作）：NOT_FOUND，提示条"这一项已不在回收站"并刷新。
  • 卷不进回收站；卷里只剩回收站中的章节时卷不能删除，彻底删除这些章节后才能删卷（S06c）。
  • 彻底删除有待审核提案或冲突的章节：提案和冲突随章节删除。
  • 档案字段或关系的生效历史仍引用某章时，保留该章作为区间锚点：单独彻底删除和清空返回明确错误，整次清空回滚；启动过期清理跳过该章并继续清理其他项目。不能将引用置空以扩大生效范围。作者可恢复并核对范围，或连同所属作品及其历史一并删除。

7. 验收要点

  • 删除作品、章节、条目后都出现在回收站，类型筛选数量正确，剩余天数正确。
  • 恢复章节且所属作品也在回收站时有一并恢复提示，确认后两者都恢复；原卷不存在时章节放入第一卷末尾。
  • 彻底删除作品后，数据库中无该作品的章节、版本、条目、对话等记录，封面文件被删除。
  • 清空后回收站为空、"清空"置灰；彻底删除和清空都没有撤销。
  • 把一项的删除时间改为 31 天前（测试桩）后重启 App，该项被自动彻底删除。
