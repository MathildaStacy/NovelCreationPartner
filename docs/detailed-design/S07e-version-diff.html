1. 页面功能

  • 按段落对比"现在的正文"与所选版本，显示恢复后会回来的段落、会消失的段落和段内改动。
  • 未变化的连续段落折叠，可逐段或全部展开。
  • 整章恢复到所选版本；恢复前自动把现在的内容存为"恢复前"版本。
  • 对比内容可以长按选择复制，方便只找回其中一段（V1 不做按段恢复）。

4. 数据与本地服务

进入页面

  • 参数：chapterId、versionId、from（'editor' 或 'list'，由 S07d 透传其来源，决定恢复后的去向）。
  • 并行调用 versions.list(chapterId)（取该版本的来源、时间、字数；也可由 S07d 直接传入）、chapters.get(chapterId)（取当前状态和 finalizedVersionId，用于对话框补充说明）、versions.diff('current', versionId)。
  • 方向约定：diff(a, b) 中 a = 现在、b = 所选版本。added = 只在版本中有（恢复后会回来）；removed = 只在现在有（恢复后会消失）；changed 的 inline 中删去的字为现在有的、新出现的字为版本中有的。

操作对应的服务

操作调用成功后
恢复这个版本versions.restore(chapterId, versionId)：事务内先生成 before_restore 快照，再用该版本覆盖正文，按 G02 4.3 重新计算状态发出 chapter.saved（及 versions.changed）；按 5.5 导航
需要明确：versions.diff 返回的 same 块是一段一块，还是已合并的连续段落。本页按"每段一块"处理，由界面按 5.2 合并折叠；G02 中"连续 3 段以上相同时折叠"应理解为界面行为，服务只返回原始块。

5. 业务规则

5.1 对比方式

  1. 按段落（以 \n 分隔，存储格式，不含段首缩进）比较；改动段落再做字符级比较（由 versions.diff 完成）。显示时每段仍按正文排版加段首缩进两字，字体为宋体，字号比编辑器小一级（16 → 15，18 → 16，20 → 18）。
  2. 空段（空行）参与比较，但显示时不画底色，只占一行高度。
  3. 改动统计中的"段"按 added、removed、changed 块分别计数。

5.2 折叠

  1. 连续 ≥ 3 段 same 折叠为一行"⋯ N 段未变化 · 展开"；1–2 段直接显示，作为改动的上下文。
  2. 默认全部折叠。展开状态只在本页有效，返回后不保留。

5.3 恢复的效果

  1. 只恢复正文，不改变标题、类型、所属卷、摘要和档案。
  2. 状态按 G02 4.3 重新计算：恢复后的正文与定稿版本完全一致 → 已定稿；本章已定稿但不一致 → 有修改未定稿；草稿、番外不变。
  3. 恢复不会自动重新定稿，也不会触发记忆提取或冲突检测。
  4. 已有的待审核提案、冲突不受影响；它们"跳到原文"时如果原句已不在正文中，按 S07 定位规则提示。

5.5 恢复后的去向

  1. from = 'editor'（经 S07a 进入，编辑器在导航栈中）：返回到该编辑器页面（移除 S07d、S07e），并传入 restored: true。编辑器重新调用 chapters.get 载入正文，清空撤销和重做栈，光标放在正文开头，显示提示条"已恢复，原内容已存为版本"（G01 提示条）。
  2. from = 'list'（经 S06b 进入，编辑器不在栈中）：把 S07d、S07e 替换为 S07 编辑器（返回时回到 S06），同样传入 restored: true，表现同上。
  3. 编辑器进入时如果带 restored: true，不按 lastCursor 恢复光标，而是放在正文开头。

6. 边界情况

  • 超长章节（5 万字以上）对比较慢：显示"正在对比…"，不设超时；在后台线程或分片计算，界面不卡顿。
  • 所选版本与现在相同（例如刚恢复过）：恢复按钮禁用，避免产生重复的"恢复前"版本。
  • 恢复一个"恢复前"版本：等同于撤回上一次恢复，规则不变，同样会再生成一个"恢复前"版本。
  • 恢复时 before_restore 快照与最近一个快照内容相同：服务不新建快照，直接复用（versions.snapshot 规则），提示条文案不变。
  • 段落很多但只有一处改动：只显示改动段及前后最多 2 段，其余折叠，打开后自动滚动到改动处。
  • 恢复进行中切到后台：事务照常完成；回到前台后按 5.5 导航。

7. 验收要点

  • 插入 AI 文本后打开"AI 插入前"版本：插入的段落显示为红底删除线（恢复后会消失）。
  • 删掉一段后打开删除前的版本：被删段落显示为绿底（恢复后会回来）。
  • 改了段内几个字：只有改动的字带底色，其余文字正常。
  • 连续 3 段及以上未变化的段落被折叠为"N 段未变化"，点击可展开；"全部展开"后全部可见。
  • 与现在相同的版本显示"完全相同"，恢复按钮禁用。
  • 恢复后回到编辑器，正文为所选版本，提示"已恢复，原内容已存为版本"；版本历史顶部多一个"恢复前"版本，打开它能看到恢复前的全部内容。
  • 已定稿章节恢复到较早版本后状态变为"有修改未定稿"；再恢复到当前定稿版本后回到"已定稿"。
  • 从 S06b 进入并恢复后，进入编辑器；在编辑器点返回回到章节列表。
  • 模拟存储已满时恢复：出现提示，正文未改变。
