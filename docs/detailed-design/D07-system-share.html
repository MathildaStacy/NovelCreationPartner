1. 内容与操作

#元素说明
1文件名称按第 2 节规则，系统显示文件名和大小
2目标由系统和已安装的 App 决定。iOS 为分享面板（含"存储到'文件'"），Android 为 Sharesheet。由本地 NativeDocumentStore 交付有界内容；Android 使用 FileProvider 授予临时读取权限，iOS 使用 UIActivityViewController，不把设备路径交给 JS

2. 文件名与类型

导出文件名MIME 类型
全部作品备份小说备份-YYYYMMDD-HHmm.ncpbakapplication/zip
单部作品备份{书名}-备份-YYYYMMDD-HHmm.ncpbakapplication/zip
导出正文{书名}.txt 或 {书名}.md；只导出一章时为 {书名}-第N章-{章节标题}.txttext/plain / text/markdown

书名为空时用"未命名作品"。文件名中的 / \ : * ? " < > | 和换行替换为"-"，总长不超过 80 个 Unicode 字符，且 UTF-8 文件名不超过 255 字节；截断始终保留扩展名。文本文件使用 UTF-8（带 BOM，方便 Windows 记事本正确识别）。

3. 结果处理

情况处理
作者选择了目标并完成iOS 仅在系统 completion 的 completed=true 时提示条"已导出"；不从打开面板推断目标完成
iOS 作者关闭面板原生返回 cancelled，回到 S15b，不提示
Android 已打开 Sharesheet原生返回 opened，提示条"已打开系统分享"。系统没有可靠的目标保存/取消结果，因此不声称已导出，也不从关闭面板推断完成
文件生成失败（存储不足）不打开面板；S15b 显示"手机存储空间不足，没有生成导出文件。请清理空间后重试。"
分享面板无法打开S15b 显示"没有打开分享面板，请重试"，附"查看详情"→ D05

临时文件：导出文件写在 App 缓存目录 document_exports/{进程会话UUID}/{导出UUID}/。分享完成或取消以及 React 重载后均不立即删除（部分目标在面板关闭后才读取文件）；下次 App 新进程启动时清理旧进程会话，保留当前进程会话；准备失败且尚未交给系统的文件立即回收（G02 第 10 节）。

4. 验收要点

  • iOS 可以"存储到'文件'"，Android 可以保存到下载目录或网盘，文件名正确。
  • 导出的 TXT 用 Windows 记事本打开不乱码。
  • iOS 取消分享不提示，完成才显示已导出；Android 只显示已打开系统分享。下次新进程启动清理旧导出，当前进程和 React 重载不得删当前分享文件。
