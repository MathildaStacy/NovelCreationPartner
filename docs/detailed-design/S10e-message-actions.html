1. 页面功能

  • 复制消息文本。
  • 把 AI 回复的结构化内容（已明确、还需要你决定、可选方向）整理成纯文本复制，方便粘贴到条目编辑或其他地方。
  • 重新生成最后一条 AI 回复；其方向已被采纳或暂存时先提示"已采纳的设定不会撤回"。
  • 查看回复详情：模型服务、模型、输入 / 输出 token、时间；出错的回复查看错误详情（D05）。
  • V1 不提供删除单条消息。需要清理时删除整个对话（S10b）。

4. 数据与本地服务

  • 打开操作表时不读取数据，使用 S10 已加载的 Message。
  • 详情弹窗：用 message.serviceId 调用 modelServices.get(serviceId) 取服务名；抛出 NOT_FOUND 时服务名显示"（已删除的服务）"。参考范围取所在对话的范围（conversations.list 结果中的 scope）。
操作调用成功后失败时
复制文本 / 复制为设定草稿 / 复制详情界面层写入系统剪贴板，不调用服务提示条提示条"没有复制成功，请重试"
重新生成conversations.regenerate(messageId)：删除原 AI 消息，用同一条用户消息和对话当前的参考范围重新调用 ai.ideate（mode 与原消息相同）S10 收到 messages.changed，显示新的生成中消息CONFLICT_STATE（已不是最后一条）：提示条"只能重新生成最后一条回复"；其他按 G01 错误
需要修改：conversations.regenerate(messageId) —— 需记录原消息的 mode（chat / more_options）以便按同一模式重新生成；Message 增加 mode 字段。重新生成前若原消息仍在生成，先中止。

5. 业务规则

  1. 操作表选项顺序固定：复制文本、复制为设定草稿、重新生成、查看详情；不可用的选项隐藏（"重新生成"在有其他回复生成时置灰而不隐藏）。
  2. 复制文本：你的消息复制原文；AI 消息只复制普通文本部分（content），不含结构化内容，去掉首尾空白。
  3. 复制为设定草稿格式（纯文本，无 Markdown 符号；空的部分整段省略）： 
    星海之境 · AI 伙伴整理（2026-10-16 14:32）

已明确
· 主角林宇，海边渔村少年
· 星海之镜会发光，镜中有失忆少女沈汐

还需要你决定
1. 沈汐为什么失忆？
2. 镜子是偶然出现，还是有人留下的？

可选方向
方向一：镜灵契约（未处理）
概括：沈汐是星海之镜的器灵……
走向：成长线
风险：契约限制过多
影响：……
    方向标题后标注状态：未处理 / 已采纳 / 已暂存。时间为消息的 createdAt，格式 YYYY-MM-DD HH:mm。
  4. 详情字段：模型服务（服务名称）、模型（message.model）、输入（usage.input）、输出（usage.output）、时间（createdAt，G01 时间格式）、参考范围（"相关已确认设定"或"仅第 12 章相关"）。token 数用千分位（G01 数字），后接"token"。用量为 null（已停止、服务未返回）时显示"未返回"。底部固定说明"token 数由模型服务返回，费用以服务商账单为准。"
  5. 重新生成只允许对当前对话的最后一条 AI 消息使用（G02 5.7）。确认对话框只在该回复有 adopted 或 stashed 方向时出现。
  6. 不提供删除单条消息（V1）：删除单条会打乱上下文、让已采纳设定失去来源，需要清理时删除整个对话。

6. 边界情况

  • 重新生成的回复中有已采纳的方向：档案中的条目保留，来源仍显示"来自 AI 伙伴"；原消息删除后这些采纳无法再从对话中撤销。
  • 长按一条较早的 AI 回复：没有"重新生成"选项。
  • 重新生成时断网或没有模型服务：按 S10 检查流程处理，原消息不被删除。
  • 消息使用的模型服务已删除：详情中服务名为"（已删除的服务）"，模型名仍显示记录值。
  • 消息文本很长（例如 2000 字的你的消息）：完整复制，不截断。

7. 验收要点

  • 长按你的消息只有"复制文本"和"取消"；长按生成中的 AI 消息没有反应。
  • "复制为设定草稿"粘贴出来的文本按规则 3 的格式，包含已明确、问题和方向，且方向标注了处理状态。
  • 只有最后一条 AI 回复有"重新生成"；其方向已采纳时先出现"已采纳的设定不会撤回"的确认，确认后档案中的条目仍在。
  • "查看详情"显示服务名、模型、输入 / 输出 token 和时间；已停止的消息用量显示"未返回"。
  • 出错的回复点"查看详情"打开 D05。
  • 操作表中没有删除单条消息的选项。
