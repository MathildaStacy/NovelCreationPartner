## 本轮修复及回归

1. **Android 保存档案崩溃**：Debug 与 Release 均复现 Fabric `ReactEditText already has a parent`。TextField 固定原生父视图，保存切换只读透明度不再重新挂载输入框。通过连续创建与更新档案复验。
2. **调整后请求被重复消费**：保留表单选择，丢弃已使用的 ContextPlan 缓存，下次生成使用新 planId。回归检查原参数重发也有新操作 ID。
3. **冲突处理后无法返回**：保存成功先解除 busy，返回拦截先于离开逻辑更新。测试加入延迟保存，直接断言导航当前 route；旧测试只匹配栈中隐藏页面的文字，不能证明已经返回。
4. **冲突页默认章名重复**：复用现有章节标题格式，S14 / S14a 及重查选择不再显示“第 1 章 第 1 章”。其他页面的旧默认章名显示另留差距。

S08a 回归增加真正的 8 项上限、取消一项后恢复其他复选框的断言。

## 保留缺口与设计同步

S09 仍缺：候选正文左右滑动切换、多次“再写一版”叠加的全局并发上限 3、S09 内 NO_SERVICE 直接弹 D03。已新增 3 条未勾选验收项。另有跨 S07 / S07d / S09 的快照标签差异：`snapshotIn` 在最新版本正文相同时直接复用，不升级为 `before_ai`；设备插入后撤销原文保留，但标签不保证为“AI 插入前”，因此这 3 页相关组合项也保留空框。不能称整个 S08/S09 已全部完成。

S07 / S09 已同步 G04：选区快捷操作、“再写一版”、“继续生成”先展示参考范围和预计消耗，再明确发送；取消预览不请求。S08 的“生成描写”本身就是发送确认。D03 是否自动继续、S05b 失败条入口、S10a token 展示仍按差距清单待统一，不擅自扩展产品行为。

S10–S13 另有并行 worktree，本轮未修改其源码、未 prune 工作树。真实模型、iOS、Release 真实服务网络与全部生命周期、低存储、长列表、读屏和大字仍未覆盖。
